# Ether-no

---

## 🎮 Game Overview

**Ether-no** is an exciting **2D Action & Adventure Roguelike** game designed for players aged 13 and up. Dive into a world where every playthrough offers a unique challenge!

### Key Features:

* **Platform:** Windows
* **Graphics:** Immersive 2D visuals
* **Control Scheme:** Intuitive Keyboard and Mouse controls
